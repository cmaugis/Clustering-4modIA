Dans ce TP, on va utiliser le jeu de données TemperaturesDepartements2018-2024.csv disponible sur la page moodle du cours.

Ce jeu de données a été construit à partir du jeu de données public “Température quotidienne départementale (depuis janvier 2018)” produit par RTE et disponible sur le site https://www.data.gouv.fr/fr/. Ce fichier donne, pour chaque jour et chaque département de France métropolitaine, les températures minimale (TMin), maximale (TMax) et moyenne (TMoy) en °C. À partir des données journalières des sept années complètes 2018 à 2024, on a calculé pour chacun des \(n=96\) départements les indicateurs climatiques suivants :

  • t_annuelle : la température moyenne annuelle (en °C),
  • t_hiver : la température moyenne en hiver (décembre, janvier, février),
  • t_ete : la température moyenne en été (juin, juillet, août),
  • tmin_hiver : la moyenne des températures minimales en hiver,
  • tmax_ete : la moyenne des températures maximales en été,

  • ampl_jour : l’amplitude thermique journalière moyenne (TMax - TMin),
  • j_gel : le nombre moyen de jours de gel par an (TMin < 0°C),
  • j_chaud : le nombre moyen de jours chauds par an (TMax \(\geq\) 30°C).

# fonction auxiliaire pour représentation géographique

visualclust <- function(departements_geojson, varquali, codes = names(varquali)){
  if (is.null(codes)) stop("Préciser les codes des départements avec l'argument codes")
  varquali <- as.factor(varquali)
  df <- departements_geojson %>%
    left_join(data.frame(code = as.character(codes), classification = varquali),
              by = "code")
  # Définir des couleurs (une par modalité)
  pal <- colorFactor(topo.colors(nlevels(varquali)), levels(varquali))

  # Créer la carte Leaflet
  # pas de fond de carte OpenStreetMap (addTiles()), bloqué hors d'un site web
  gcarte <- leaflet(df) %>%
    addPolygons(
      fillColor = ~pal(classification),  # Couleur en fonction de la classification
      weight = 1,
      opacity = 1,
      color = "black",
      dashArray = "3",
      fillOpacity = 0.7,
      popup = ~paste("Département : ", nom, "<br>Classification : ", classification)
    ) %>%
    addLegend(
      pal = pal,
      values = ~classification,
      title = "Classification",
      opacity = 1
    )
  return(gcarte)
}

Vous pourrez comparer deux clusterings à l’aide d’un graphique alluvial en utilisant la fonction alluvtwoclust() suivante :

alluvtwoclust<-function(classif1,classif2,nom1,nom2){
  clust1<-paste0(nom1,"-k",classif1)
  clust2<-paste0(nom2,"-k",classif2)
  Tab<-melt(table(clust1,clust2))
  g<-ggplot(Tab,aes(y=value,axis1=clust1,axis2=clust2))+
    geom_alluvium(aes(fill=clust1))+
    geom_stratum(width = 1/12)+
    geom_text(stat = "stratum", aes(label = after_stat(stratum)))+
    theme(legend.position = "none")
  return(g)
}

}

1.4 Classification avec l’algorithme fuzzy c-means

1.4.1 Présentation

Avec les algorithmes de clustering précédents (Kmeans, PAM) nous obtenons une classification “dure” au sens que chaque individu ne peut appartenir qu’à une seule classe et chaque individu participe avec le même poids à la construction des classes. Une classification dure \(\mathcal{P}_K=\{\mathcal{C}_1,\ldots,\mathcal{C}_K\}\) peut se traduire en une matrice \(Z=(z_{ik})_{\underset{1\leq k \leq K}{1\leq i \leq n}}\) avec \(z_{ik}=1\) si \(i\in\mathcal{C}_k\) et 0 sinon. Dans cette section, nous allons nous intéresser à une adaptation de l’algorithme des Kmeans, appelée fuzzy c-means. L’idée est de retourner une classification fuzzy c’est-à-dire une matrice \(W=(\omega_{ik})_{\underset{1\leq k \leq K}{1\leq i \leq n}}\) avec \(\forall i,\ k,\ \omega_{ik}\geq 0\) et \(\forall i,\ \underset{k=1}{\stackrel{K}{\sum}} \omega_{ik}=1\). On donne ainsi plutôt un poids \(\omega_{ik}\) que l’individu \(i\) appartienne à la classe \(\mathcal{C}_k\).

L’algorithme fuzzy c-means a pour fonction objective

\[ \underset{W,\{m_1,\ldots,m_K\}}{\mbox{argmin}}\ \underset{i=1}{\stackrel{n}{\sum}}\underset{k=1}{\stackrel{K}{\sum}} (\omega_{ik})^\gamma\ \|x_i - m_k\|^2 \] où \(X=(x_1,\ldots,x_n)'\) est la matrice des données, \(\gamma\in[1,+\infty[\), \(m_k\) est le centre de la classe \(\mathcal{C}_k\).

Dans le même principe que l’algorithme des Kmeans, l’algorithme fuzzy c-means est un algorithme itératif :

  • Step 1: Initialisation des poids \(W^{(0)}\)
  • Step 2: A l’itération \(r\), on calcule les centres des classes

\[ m_k^{(r)} = \frac{\underset{i=1}{\stackrel{n}{\sum}} (\omega_{ik}^{(r-1)})^\gamma x_i}{\underset{i=1}{\stackrel{n}{\sum}} (\omega_{ik}^{(r-1)})^\gamma} \]

  • Step 3: Mise à jour des poids (\(\gamma>1\)) \[ \omega_{ik}^{(r)} = \left[\underset{\ell=1}{\stackrel{K}{\sum}} \left(\frac{\|x_i - m_k^{(r)}\|^2}{\|x_i - m_\ell^{(r)}\|^2}\right)^{\frac{1}{\gamma-1}} \right]^{-1} \]

  • Step 4: Si \(\|W^{(r)} - W^{(r-1)}\|<\) seuil, on s’arrête, sinon on retourne à l’étape 2.

En général, la puissance choisie sur les poids est \(\gamma=2\). Dans le cas \(\gamma=1\), on retrouve l’algorithme des Kmeans.

2.2 Fonction auxiliaire pour la suite

Pour la suite du TP, on pourra utiliser la fonction auxiliaire barplotClus() suivante, qui permet de tracer la répartition des modalités de variables qualitatives pour chaque classe d’un clustering donné.

# clust : clustering étudié
# Data  : jeu de données (variables qualitatives)
# J     : indices des variables de Data à représenter
# output : liste de graphiques (un par variable de J) donnant, pour chaque classe de clust,
#          la répartition (fréquences) des modalités de la variable

barplotClus <- function(clust, Data, J) {
  p <- list()
  for (j in seq_along(J)) {
    # fréquences des modalités de la variable J[j] dans chaque classe
    freq <- as.data.frame(prop.table(table(clust = clust, value = Data[, J[j]]), margin = 1),
                          responseName = "perc")
    p[[j]] <- ggplot(freq, aes(x = clust, y = perc, fill = value)) +
      geom_bar(stat = "identity") +
      labs(x = "Classe", y = "Fréquence", fill = colnames(Data)[J[j]])
  }
  return(p)
}

2.3 Clustering à l’aide des Kmodes

Dans cette partie, nous allons utiliser la méthode des Kmodes introduite par Huang (1998). Rappelons que cette méthode est une extension des Kmeans dans le cas des données qualitatives. Les modifications par rapport aux Kmeans sont

  • le changement de distance : on utilise la dissimilarité basée sur l’appariement simple

\[ d(\mathbf{x}_i,\mathbf{x}_\ell) = \underset{j=1}{\stackrel{p}{\sum}}\ \mathbb{1}_{x_{ij}\neq x_{\ell j}} \]

  • le centre d’une classe est calculé en fonction des fréquences des modalités majoritaires présentes dans cette classe: pour la classe \(\mathcal{C}_k\),

\[ \mathbf{m}_k=(m_{k1},\ldots,m_{kp}) \textrm{ avec } m_{kj}= \underset{u_1,\ldots,u_{s_j}}{\mbox{argmax}}\ \underset{i\in\mathcal C_k}{\sum}\ \mathbb{1}_{x_{ij}= u_{s_j}} \]
